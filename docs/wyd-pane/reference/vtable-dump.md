## Using this table

- To find the property handler for a widget, use slot `0x60`.
- To find the draw function, use slot `0x0c`.
- To find input handlers, use `0x18` (key) and `0x1c` (mouse).
- To find the hit test, use `0x3c`.
- To find the layout update, use `0x70`.
- To find the text serializer, use `0x6c`.
